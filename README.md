# Todo List

Meu terceiro projeto: lista de tarefas interativa com persistência local.

## O que aprendi aqui

- `localStorage` para persistência de dados
- Arrays: `map`, `filter`, `find`, `push`
- Event delegation (delegar clicks na lista)
- Filtros dinâmicos (todos, pendentes, concluídos)
- Animação CSS com `@keyframes`
- Escape de HTML para segurança

## Funcionalidades

- Adicionar tarefa
- Marcar como concluída (checkbox)
- Excluir tarefa
- Filtrar por status
- Estatísticas em tempo real
- Persistência no localStorage

## Como visualizar

Abra o `index.html` no navegador.
